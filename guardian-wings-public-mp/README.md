# 翼路平安公众端小程序预览版

这是从母项目中独立摘出的公众端微信小程序工程。母项目保留不动，警务端、PC 指挥平台和群聊协作模块不纳入本工程。

## 当前范围

- 普通用户登录、注册、找回密码
- 首页、新闻、早报、科普入口
- 公众举报、我的举报、举报详情
- 识鸟百科、鸟类详情、收藏
- 志愿活动、活动详情、我的活动
- 我的、资料、设置、积分、收藏、法律法规、应急救助

## 不包含

- 公务段/警务端登录
- 警务任务中心、工作台、群聊、预警
- PC 指挥平台派发接口
- 后台新闻管理页面

## 云端依赖

预览版继续复用现有阿里云 uniCloud 服务空间。当前本地仅保留公众端相关云函数副本：

- `gw-public-user`
- `gw-public-report`
- `gw-bird`
- `gw-volunteer`
- `gw-news-admin`
- `gw-morning-brief`
- `gw-news-crawler`

当前没有改动已部署服务空间中的云函数或数据库。

## 运行方式

优先使用 HBuilderX 打开本目录，选择微信小程序运行。

如果使用 CLI，需要先安装依赖：

```bash
npm install
npm run dev:mp-weixin
```

当前仓库未包含 `node_modules`，本次拆分没有自动安装依赖。
